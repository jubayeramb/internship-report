\section{Problem Domain}

\par \textbf{WeCycle} is a software solution for junk removal business. We help haulers get jobs and the customers there unecesarry items cleaned. We mainly take our bookings by our website. User can create a booking for junk removal service then we reach out to a hauler give him the task. After the work is done we get paid from the customer and then use pay the hauler after cutting our commission. As \textbf{Full-Stack Web Development}, my work is make this process as automated and smooth as possible. I work on  WeCycle Dashboard Application (WCAPP), ArrayQ and Wecycle website to improve conversion and management easier and implement new features for both customer and haulers.

\par It is a great opportunity for me that I can work with experience team as I am the most junior stuff on the team. I get to learn and guided my all on my work. The work I have done during intership days are:
\begin{itemize}
    \item We had to migrate from a Antd component library to a new Shadcn component library. As the Antd components was breaking when we are trying to upgrade our code bases with new tools. So I refactored all the Antd components.
    \item The whole dashboard design was made responsive as the user might use different devices with different screen sizes. It make the user experience better.
    \item I had to make the code reusable and modular. Using hooks and other abstraction techniques.
    \item I had to reuse existing code to make consistent development through codebase.
\end{itemize}

\section{The Reality Check: Academia vs. Industry}

\par The differnce is noticeable between university learning the Industry standar which are:

\begin{itemize}
    \item \textbf{Theory vs. Reality:} University projects need to be done in limited time frame. So we mostly focus on building features. But in real world the most projects are long running and spend 90 percent for development time on polishing rather than developing.
    \item \textbf{Tool Stack:} In university, we learn c, c++, java which are not the top choice of most of the industry. The usage level is under 10 percent for most of them. We need to learn the modern tool stack separately to meet the industry standard.
    \item \textbf{Team work:} University mostly focus on individual skills and our projects are mostly solo made. But in practice projects are made by a team and we need to learn collaboration and manage project as a team using tools like git and github.
    \item \textbf{Legacy Code:} In university we always do a new project in every semester. However work in a industry might have 5-year-old code and  we need to figure out what the original developer was thinking and understand the codebase.
\end{itemize}
